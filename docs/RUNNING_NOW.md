**为什么要平滑**：诊断发现部件掩码是「铺满全图的碎斑」——熵 4.45~4.96/5.28、
平均 13 个连通块、邻居相关只有 0.27、富集比 1.12×（GAP 是 1.37×）。
根因：1×1 检测器 + 逐格标准化 + 输出只是全图加权平均，模型没有动力让掩码成片。
3×3 平滑把邻居相关拉到 **0.656**（实测），这是把它变回「区域」的最小改动。

## 四、判读规则（避免把噪声当结论）

- 基线自身种子散布 ±0.2（5,395 口径实测 89.06/88.75/89.04；全训口径 89.61~89.94）；
- 任何单粒 Δ < 0.2 一律写「未检出」；要下结论必须 ≥3 粒同向；
- 主表固定 `swa_f0.5`，其余权重只作稳健性检查，不按 test 挑最好的那个。
