文献：Wei, Song, Mac Aodha, Wu, Peng, Tang, Yang, Belongie.
Fine-Grained Image Analysis With Deep Learning: A Survey. TPAMI 44(12), 2022.

一、综述的骨架

第五节把"细粒度识别"分成三大范式，这是全篇的索引：

V-A 定位-分类子网络（先找部位，再分类）
  V-A1 检测 / 分割         需要框或部位标注
  V-A2 深度滤波器          把卷积通道当部位探测器，不需要标注
  V-A3 注意力机制          学习"松散定义的区域"，不需要部位定义
  V-A4 其他

V-B 端到端特征编码（不显式找部位，直接造更强的特征/损失）
  V-B1 高阶特征交互        Bilinear / 协方差 / 核池化
  V-B2 特定损失函数        ← 我们完全没碰过的一整支
  V-B3 其他（辅助任务）    破坏-重建、拼图、对抗生成

V-C 借助外部信息           网络弱标注数据、多模态、人在回路

三、三个读数

读数一：我们的分数已经在 R50 公开成绩的第二名，但这不是好消息。

上面这些方法全部用 ImageNet-1k 预训练，我们用的是十亿图弱监督权重。
我们自己量的冻结探针：SWSL 74.62，a1 只有 64.77，特征强 9.9 个点。
也就是说，我们用更强的权重，才追平了别人的方法分。
按这个换算，我们的"方法"其实还欠着一截——这正好说明方法层还有空间，
而不是"已经到头了"。

读数二：R50 里唯一明显在上面的是 PMG（89.6），而且它和我们同分辨率（448）。

PMG 的做法是渐进多粒度拼图：把图切成 n×n 块打乱，n 从 8 到 4 到 2
分阶段训练，参数在阶段间接续，最后一步用原图。测试时完全撤掉拼图，
把各阶段输出相加。也就是说，它没有加任何模块，只在"训练时给网络看什么"上做文章。

这一点和我们自己的 cam_quad 是同一族，但你当初的直觉被我们用错了三处：

| | PMG | 我们的 cam_quad |
|---|---|---|
| 施加位置 | 主分支的输入 | 辅助分支，权重 0.1~0.2 |
| 粒度安排 | 8×8 → 4×4 → 2×2 分阶段，由粗到细 | 全程固定 2×2 |
| 训练目标 | 每阶段单独分类，最后原图收尾 | 每一轮都同时跑两路 |

辅助分支权重 0.2 意味着拼图只贡献 20% 的梯度，而且从头到尾一个样，
既没有"先破坏后收敛"的课程，也没有独占主干的时刻。
它测出 87.67 不说明拼图没用，说明这个用法没用。

读数三：V-B2「特定损失函数」是我们唯一一整支没碰过的。

这一支的共同点是：不改结构、不加参数，只改损失，因此和我们已经扫过的
结构类、增强类变量全部正交。代价也最低（加几行、不增加前向次数）。

| 方法 | 机制 | 公开成绩 |
|---|---|---|
| MaxEnt [107] | 最大化输出熵，抑制过度自信 | BC 84.1→85.3 |
| Pairwise Confusion [108] | 同类样本的预测分布互相靠拢，去掉样本特异伪影 | BC 84.1→85.6 |
| Sun [110] | 抑制 CAM 最显著区 + 难类梯度加成 | R50 88.6 |
| CIN [109] | 通道级对比，拉同类推异类 | R101 88.1 |
| API-Net [111] | 成对图像学"这对差异在哪" | R50 87.7 |
| MC-Loss [112] | 通道分组，组内紧凑、组间分散 | BC 86.4 |

对得上我们诊断的是前两个：训练集 100%、错得自信、错在 8 个几乎一样的类。
MaxEnt 和 Pairwise Confusion 正好是冲着"过度自信"和"记样本"去的。

五、四个方向的排序

D1 测试时增强（TTA）
  代价：零训练，只需一次推理。已有 swa_f0.5.pth 直接测。
  预期：+0.3 ~ 0.8。报告里写的"多视图 0.3~0.8"是估计，还没实测。
  风险：无。哪怕不涨，也是一条干净的负结果。

D2 PMG 渐进多粒度拼图
  代价：中。复用 cam_quad 的切块代码，改成主分支 + 阶段式课程。
  预期：+0.5 ~ 1.5。综述里 R50 第一名，同分辨率，无额外标注。
  风险：PMG 原文 300 轮 SGD，我们 50 轮 AdamW，课程被压缩后效果可能打折。

D3 损失层（MaxEnt / Pairwise Confusion）
  代价：低。MaxEnt 三行；Pairwise Confusion 需要一个同类配对采样器。
  预期：+0.3 ~ 0.8。BC 上 +1.2 / +1.5，但我们的 baseline 强得多。
  风险：和已有的 label smoothing 0.05 部分重叠，可能互相抵消。

D4 提高分辨率（448 → 576）
  证据：表 IV 显示 224→392 单调上升、392 时仍未饱和。
  但这条证据有边界条件：CUB 原图短边中位 357 像素，最大 500 像素，
  没有任何一张能原生喂满 512。448 配 0.875 的裁剪比，resize 目标是 512，
  也就是说每张图都在上采样。表 IV 的上涨是"逼近原生分辨率"，
  不是"分辨率越高越好"——越过 500 之后只剩插值。
  结论：这条方向基本被数据集本身封死了，不必去争 448 的约束。


六、下一步

先做 D1，因为它不占训练资源，不改变任何设定，只是把已有权重测得更充分。
然后再按 D2 → D3 的顺序排。


附：D2 的落地形态（设计，不含代码）

1. 施加位置：主分支的输入。不是辅助分支 —— 这是和 cam_quad 最本质的差别。
   实现位置在 dataset 侧（collate 之后、forward 之前），不碰 model。

2. 切块：n×n 等分，随机置换后拼回。n=8 时每块 56×56，几乎只剩局部纹理。
   四块的拼回逻辑可以照搬 model/cam_aug.py 里 _reassemble 的写法。

3. 课程（按 epoch 比例）：
   0    - 0.25  n=8
   0.25 - 0.5   n=4
   0.5  - 0.75  n=2
   0.75 - 1.0   原图（这一步让训练末端的输入分布和测试一致）

4. 测试：完全撤掉拼图，单张原图前向。这一条我们本来就做对了。

5. 第一版请把 cam_crop / cam_consistency 关掉，只留拼图 + mixup，
   否则一旦有变化分不清是拼图还是辅助分支的功劳。

6. 需要新写的只有两块：切块置换函数（约 20 行）和课程表（几行）。
   其余全部复用现有训练循环。

一条提醒：原文是 300 轮 SGD，我们 50 轮 AdamW。课程被压到 12 轮一段，
可能来不及收敛。如果第一版只掉不涨，先看每段的验证曲线是不是"还没学会就换段"，
再决定要不要把 epochs 加长。
