# 计划：ResNet-50 单视图破 90（第二版汇报的主线）

## 目标与硬约束

- 骨干：ResNet-50（可以改结构，不能换成 ViT / R101 / 大模型）。
- 监督：只用图像级标签，不碰 bbox / parts。
- 评测：**单个权重、一张图前向一次**（短边 512 → 中心裁 448）。
- 禁止：蒸馏、集成、多视图 TTA、把 val 并进训练、外部数据。
- 现有基线：**89.02**（SEED=42；另两粒 88.78 / 88.56，均值 88.79）。
- 目标：单视图 **> 90.00**，且提升来自结构/机制，不是训练技巧的堆叠。

## 已知事实（都是自己测的，不是猜的）

1. 在 layer4（14×14，448 输入）后面加一切聚合模块都无效或有害：
   attn_pool 88.18、d512/4 层 88.51、49 token 88.82、无注意力控制臂 88.83、SE 88.75、
   TokenLearner 与基线相同（且熵塌缩到 0.004 也没差别）、双线性 86.45、GeM 88.42。
2. layer4 的线性探针 85.99，layer3 只有 50.74，拼接 85.17 —— **简单融合浅层反而更差**。
3. 区域探针：头部 82.65、同面积随机框 38.92、全局 87.33 —— 部位信息存在，但「切出来单独看」
   不如「整张一起看」。
4. ViT-B(CLIP) 91.35：CLS 90.81、patch 平均 45.62 —— ViT 的增益在**学会的全局聚合**，
   而且它的 token 一直保持 28×28。
5. 背景掩码 88.47（更差）、背景裁剪 val 84.76（明显更差）—— 背景不是敌人。

综合：R50 的问题不是「怎么聚合 14×14 的格子」，而是**到 layer4 时空间细节已经被 stride-16
的最后一组下采样抹掉了**。所有在 14×14 上做加权的尝试，都是在已经很粗的表示上重新分配
权重，能动的信息量本来就有限。

## 假设与对应实验

### H1（分辨率/粒度）—— 最高优先级，最便宜
把 layer4 改成 stride-8（dilated，conv2 dilation=2、downsample 与第一层 stride 改 1），
448 输入下特征图从 14×14 变成 28×28，与 ViT 的 token 数一致，且保留预训练权重的几何含义。
- 实验 `r50_s8`：只改这一处，其余配方与基线逐项相同，50 epoch。
- 判定：与同种子基线逐张配对 McNemar。Δ ≥ +0.3 才继续，否则这条线直接砍掉。
- 风险：BN 统计漂移、预训练权重与新感受野不匹配；用 3 epoch warmup + 分层学习率缓解。

### H2（高分辨率上的全局混合）—— 只有 H1 成立才做
在 28×28 的 784 个 token 上做一个**轻量**全局自注意力块：
- pre-LN，QKV 走 256 维瓶颈，单头/4 头，输出投影零初始化（初始等价于恒等）。
- 位置编码用 2D 正弦（可学），drop_path 0.1。
- 对照臂 `r50_s8_ctrl`：同样的投影与残差、**去掉注意力**，只做逐点 MLP。
- 两个臂都要跑，否则无法区分「涨点来自注意力」还是「来自多出来的参数/残差」。
- 预期参数量 ≈ 1.5M（相对 24M 约 6%），不能再大——5400 张图容不下。

### H3（多粒度，正交）—— 并行排在第二张卡/空闲时
PMG 论文 89.6 是 300 epoch + ImageNet 权重，我们 50 epoch + SWSL 只有 89.25，且关掉了
CAM 分支。用 200 epoch 重跑，并尝试保住 CAM 分支（若冲突则记为单变量）。
- 这是 Table 2 里 R50 单前向的最高分，也是「粒度」假设的独立证据。

### 备选（前三条都不动才上）
- Cross-X 式跨层注意力（layer3 作 K/V、layer4 作 Q）。
- DF-GMM 式低秩基分解（按重建误差划分判别区域）。
- NAC/DFL-CNN 式可学习部件检测器 + 峰值响应池化。

## 评测与统计

- 每个实验跑完在 test 上做单视图评测，与**同种子基线**逐张配对 McNemar + bootstrap CI。
- 筛选阶段允许看 val，但 val 只有 599 张（SE≈1.2pp），**不用于挑 0.3 量级的差异**。
- 最终结论必须 3 粒种子（42/1/2）复现，且三粒方向一致。
- 所有跑过的实验都留在 EXPERIMENT_INVENTORY.md 里，包括负结果。

## 计算预算

单卡 3090，R50@448/bs16 约 27 s/epoch（普通）、PMG 约 4×。
- H1：25 min
- H2 两臂：2 × 35 min
- H3：约 7 h（后台）
合计约 9 h，可以一个晚上排完。

## 修订（2026-10-27 深夜）：测试允许多次前向，只禁 TTA

用户明确：「训练多次前向是 OK 的，测试看情况——如果是机制要求两次，那可以；
如果只是单纯比较 low 的办法（TTA），就不行。」

这条把文献里真正有效的那类机制解锁了。两条关键诊断：

**1. 单区域（CAM 框）融合的上限**：global 88.78 / crop 84.67 / 概率平均 88.56 /
oracle 90.01。单区域放大没有足够空间。

**2. 多区域（GT 头 + 身体 + 整图）再编码的上限**：global 88.75 / head 62.34 /
body 71.07 / 平均 87.78 / **oracle 91.85**。头/身体两路合计救回 180 张 global 错的图，
global 独有 426 张。

结论：单区域不够，**多区域（2–3 路）再编码才有 +1 以上的空间**。这也正是
MA-CNN/GCL/FDL 的做法（它们的增益本来就来自多裁），只是我们要把融合做成
端到端学习的一部分，而不是测试期的概率平均。

### 为此新增的实现

- `MODEL.cam_fuse`：训练时把「整图 + CAM 框放大」两路 logits 按可学习 β 融合
  （`logits_fused = logits + β·logits_crop`，β 初始 0，初始测试与基线逐位等价）；
  测试时模型内部走两次前向。这不是 TTA：第二路是模型自己选的区域，β 是训练出来的。
- 队列 `scripts/queue_r50_90_b.sh`：`r50_camfuse`（margin 1.3）与
  `r50_camfuse_m16`（margin 1.6，更宽上下文）。
- 若两路有效，下一步扩到三路（整图 + 紧裁剪 + 宽裁剪），对应 GT oracle 91.85 那个实验。

| 代号 | 机制 | 代码 | 关键超参 |
|---|---|---|---|
| pa（pa_aux） | K 个 1×1 检测器（sigmoid 掩码）+ 部件间自注意力 + 逐部件 CE + MA-CNN Div/Dis | `model/part_attn.py:PartAttention` | K=4, `pa_aux_w=0.5`, `pa_div_w=0.1` |
| pa2 / pa3 | 竞争分配（每格在 K 个部件间 softmax）+ 负载均衡 + 空间归一化；tau 控制锐度 | 同上（`compete=True`） | pa2 tau=1，pa3 tau=0.1 |
| pa4 | **通道硬分组**：`Conv2d(C,K,groups=K)`，第 k 个部件只看第 k 组通道，部件特征只在本组通道上池化 | 同上（`grouped=True`） | K=4, tau=0.1 |
| pa_slots | Slot Attention：可学习 slot 作查询、跨 slot softmax、按 token 归一化、GRU 迭代、2D 位置编码 | `model/part_attn.py:SlotParts` | K=4, iters=3 |
| rerank | **部件裁出来重新编码**：掩码取框（带 NMS 兜底）→ 从原图裁剪放大 → 同一骨干重编码 → 部件间自注意力融合 | `Classifier._forward_part_rerank` + `PartFusion` | K=2，测试 3 次前向 |

50 轮，直接判定该变体无效。pa（overlap 1.00）与 pa2（0.62→0.98）都是这样被否掉的。

# 2026-10-29 修订：从「部件分离」转向「部件局部」

## 结论性修正（有数据支撑）

1. **互斥不是目标**。真实部位天然重叠（翅根连身体、喉在胸前、眼睛嵌在头部框）。
   实测：layer3 上把 `pa_overlap` 从 0.23 压到 **0.019**，test 88.71，与 layer4 的 88.83
   （三 seed 均值）没有区别；而强分离（JS 0.35）会把部件推到背景（富集比 0.58×）。
   → **overlap / IoU 不是有效调节轴，从判据里移除。**
2. **不学残差（替换出口）时，局部性是必要条件**：注意力图是唯一出口，图一散，
   输出就退回 GAP（`tl_replace` 实测就是 GAP 本身：JS=0、IoU=1、富集比 1.37×）。
3. **双侧熵目标不可用，单侧「上限」可用**：`(ent−target)²` 会同时惩罚太尖，在替换出口上
   造成 −3.2~−3.8 的冷启动；新增 `ent_mode=ceiling`（只罚太散）+ `ent_ramp` 退火
   （前 x% 轮内上限从 lnN 线性降到目标），初始梯度为 0，绕开冷启动。
4. **正则权重必须与 CE 同量级**：ceil 0.5 的初始罚项是 22.9，`tl_reg_w=0.5` 时等于 CE 的 7 倍。

## 当前阶段的假设与判据

**假设 H4（局部性）**：在替换出口下，把每个部件压到一个局部区域（熵上限 0.5~1.5），
同时用逐 token CE 把它们锚在可分类的物体区域上，就能让「部件」提供 GAP 之外的证据。

**判据（三轴同时看，缺一不可）**：

| 轴 | 达标线 | 工具 |
|---|---|---|
| 落在物体上 | 富集比 **> 1.37×**（GAP 水平） | `probe_mask_on_object.py` |
| 每个部件可分类 | 逐 token CE ≤ 1.0 | 训练日志 `train_logits_tl` |
| 部件之间提供不同证据 | token 特征去中心余弦 **明显低于 1**（掩码重叠无所谓） | `probe_token_stats.py` |
| 最终 | test Δ ≥ +0.3 且 p < 0.05，**三 seed 同向** | `compare_runs.py` |

**队列**：见 `docs/QUEUE_NOW.md`（F 轮 = 熵上限 1.5/1.0/0.5(+退火)/0.5(残差)，JS 全关）。
